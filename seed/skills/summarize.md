# Summarize

When asked to summarize code or a project:

1. Identify the project type (language, framework, purpose)
2. List key files and their roles
3. Describe the architecture in 3-5 bullet points
4. Note dependencies and their purposes
5. Highlight any unusual patterns or notable design decisions
6. Keep the summary under 500 words unless asked for more detail
